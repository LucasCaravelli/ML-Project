## Latex usage

Tables are `booktabs`-style. Add to the report preamble:

```latex
\usepackage{booktabs}
\usepackage{graphicx}
```

Then `\input{path/to/table_main_results.tex}` for tables and
`\includegraphics[width=\linewidth]{path/to/fig_size_distribution.pdf}`
inside a `figure` environment for figures.
